Плагин `.obsidian/plugins/tasks-mover/` добавляет команды для работы со списками задач (`tasks.md`, `tasks-future.md`, `ideas.md`, `tasks-snoozed.md`). Ниже — команды с дефолтными хоткеями. Переназначить можно в Settings → Hotkeys (поиск `Tasks Mover`).

## `Ctrl+Shift+X` — Move task…

Открывает у курсора меню перемещения задачи. Переносит задачу под курсором **вместе со всеми её вложенными подпунктами** в выбранный файл и позицию.

- Активна только когда курсор стоит на строке задачи или её подпункте в одном из 4 task-файлов.
- Позиции: для `tasks.md` — `Week begin/end` и `Week+ begin/end`; для остальных — `begin/end`.
- `begin`/`end` вставляют перед первой / после последней задачи в области, пропуская frontmatter, заголовки и вводные/подвальные блокквоты.
- То же меню доступно по правому клику (пункт **Move**). У пунктов показываются иконки файлов из Iconize.

## `Ctrl+Shift+D` — Insert created date

Вставляет в позицию курсора маркер даты создания ` ➕ YYYY-MM-DD` с сегодняшней датой. Если есть выделение — заменяет его.

## `Ctrl+Shift+S` — Split task tail into child bullet

На строке задачи переносит весь текст **после курсора** в дочерний bullet-подпункт.

- Маркер `➕ YYYY-MM-DD` (где бы ни стоял в строке) остаётся на строке задачи.
- Ведущие разделители в перенесённом хвосте убираются: тире (`—` `–` `-`), точка `.`, запятая `,`.
- Курсор остаётся в конце заголовка задачи (перед `➕`), чтобы продолжить правку названия.
- Если после курсора нет значимого текста — команда не срабатывает.

**Пример** (курсор после `»`):

```
До:
- [ ] Прочитать статью «…запросов» — https://example.com/article/1019820/ ➕ 2026-06-30

После:
- [ ] Прочитать статью «…запросов» ➕ 2026-06-30
	- https://example.com/article/1019820/
```

## Хоткеи других плагинов

`Ctrl` здесь — модификатор, который Obsidian называет `Mod`: на Windows и Linux это `Ctrl`, на macOS — `Cmd`.

### Правка текста

- `Ctrl+D` — выделить слово под курсором, повторное нажатие добавляет к выделению следующее такое же вхождение
- `Ctrl+Shift+Alt+D` — дублировать строку
- `Ctrl+Enter` — вставить пустую строку ниже и перейти на неё

### Заголовки и списки

- `Alt+1`, `Alt+2`, `Alt+3` — заголовок первого, второго, третьего уровня
- `Alt+T` — открыть диалог задачи (Tasks)
- `Ctrl+Shift+L` или `Alt+B` — сделать строку пунктом списка
- `Ctrl+↑` / `Ctrl+↓` — поднять / опустить пункт списка вместе с вложенными
- `Ctrl+Shift+↑` / `Ctrl+Shift+↓` — то же самое, второй набор клавиш

### Свёртка

- `Alt+-` — свернуть на уровень глубже
- `Alt+=` — развернуть на уровень
- `Ctrl+Shift+-` — свернуть всё
- `Ctrl+Shift+=` — развернуть всё

### Прочее

- `Ctrl+Shift+C` — открыть панель Claude
- `F4` — показать текущий файл в дереве файлов
